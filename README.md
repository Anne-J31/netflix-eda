# 🎬 Netflix Exploratory Data Analysis (EDA)

A comprehensive data analysis project examining Netflix's global content library, growth patterns over time, target demographics, and primary content genres.

---

## 📌 Project Overview
This project analyzes Netflix's dataset containing titles, genres, release years, cast, directors, and ratings. The analysis delivers key business insights into how Netflix's content strategy has evolved over time and where its acquisition focus currently lies.

---

## 📊 Key Findings & Insights
- **Content Distribution:** Movies make up approximately **70%** of the platform's overall catalog (6,129 Movies vs. 2,664 TV Shows).
- **Peak Growth Period:** Content additions experienced exponential expansion starting in 2016, reaching a historical peak in **2019** before tapering off.
- **Top Content Producers:** The **United States** leads in total productions, with **India** holding the second spot due to heavy regional expansion (Bollywood/Asian content).
- **Dominant Genres:** **International Movies**, **Dramas**, and **Comedies** rank as the top genres on the platform.
- **Audience Targeting:** **TV-MA** is the single most common rating, followed by **TV-14**, showing a heavy focus on mature and young adult audiences.
